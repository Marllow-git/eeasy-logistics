# apps/driver

- Expo SDK 58 (managed, dev client) + Expo Router. Root `app/_layout.tsx` gates with `Stack.Protected` from `src/domain/gate.ts`; `app/index.tsx` (unprotected) redirects to the allowed group's first screen (a protected `/` gives "Unmatched route"). Groups `(auth)` sign-in, verify, account (formSheet); `(setup)` pin, permissions; `(app)` home (leg 2 adds tabs); `update` (426).
- Layers (DRV-1, `.dependency-cruiser.cjs`): `app/` + `src/ui` → `src/domain`, `src/sync`, `src/i18n`, `src/observability` (UI may import only `src/platform/permissions.ts` of the adapters); `src/sync` → `src/platform`, `src/domain`; `src/platform` → nothing of ours; `src/domain` pure. Rule `driver-pin-never-in-sqlite`.
- Sync composition `src/sync/driver-app.ts` (`initDriverApp(locale)` once in the root layout, `driverApp()` elsewhere): `Session` (refresh token + ids in secure store, access token in memory, single-flight per context + SQLite `refresh_lease` 30 s), `createDriverFetcher` (X-App-Version/X-App-Platform/Accept-Language/bearer; 426 → update, 401 token_expired → refresh+retry once, device_revoked/token_invalid → end, 403 account_suspended → read-only), `PinVerifier` (ADR-0034, react-native-quick-crypto `argon2`, Node's `crypto.argon2Sync` in Jest).
- Strings: `@eeasy-logistics/i18n/driver` (`driverMessage`, `driver` namespace incl. `native.*` permission strings that `app.config.ts` puts in InfoPlist locales). Language in expo-sqlite kv-store; change = `forceRTL` + reload.
- Config: only `EXPO_PUBLIC_*` via `@eeasy-logistics/config/driver`; literal `process.env.EXPO_PUBLIC_X` reads are required for Metro inlining. Hermes has no `globalThis.crypto`: `installRandomValues()` (expo-crypto) runs in `initDriverApp` so contracts' `uuidv7`/request ids work.
- Tests: Jest `test/` (`helpers.ts`: in-memory secrets, `node:sqlite` for the lease; tsconfig types include `node`); `test:architecture` cruises `app src test`. Maestro flows `maestro/*.yaml` with `-e LOCALE=ar|en -e METRO_PLAIN=host:port -e STUB_URL=… -e SHOTS=dir`; drivers from `maestro/fixtures/plant-drivers.sql` on a scratch db; codes from the WhatsApp stub `/v1/last-code`.
- Native builds (local only, `ios/` `android/` gitignored): `npx expo prebuild --no-install`, `pod install`, `xcodebuild -workspace ios/EeasyLogisticsDriver.xcworkspace -scheme EeasyLogisticsDriver -sdk iphonesimulator`, `./gradlew app:assembleDebug -PreactNativeArchitectures=arm64-v8a`. A JS/native version skew (`expo install --check`) shows as "Cannot find native module" at run time. Android: `adb reverse` the API and Metro ports.
- Quirks (2026-11-02): iOS reload right after first commit crashed Fabric (delay 300 ms); iOS dev build drops the first JS touch after the direction reload; Android edge-to-edge keeps the footer under the keyboard; `expo-screen-capture` blanks Maestro screenshots of the PIN screen on iOS; `expo start` rewrites `tsconfig.json` include (restore before committing); the post-sign-in PIN OTP meets the 60 s cooldown (screen waits, then sends).
