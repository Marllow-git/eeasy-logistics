# eeasy-logistics · core

Standalone last-mile delivery + WMS for merchants with own drivers and stock. pnpm + Turborepo monorepo. Phase: wave 0 foundation (code exists since PLAT-1, 2026-10-31).

## Source map
- `apps/api` NestJS API, three bounded contexts → `mem:api/core`
- `apps/web` Next.js 16 App Router, merchant/recipient/auth route groups → `mem:web/core`
- `apps/admin` Next.js 16 platform console, own image and hostname (ADR-0038, WEB-19) → `mem:admin/core`
- `apps/driver` Expo Router driver app → `mem:driver/core`
- `packages/config` the only `process.env` reader; Zod schemas, `Secret` wrapper, credentials AES-GCM, production refusals (`src/refusals.ts`). Entry points: `node.ts` (server), `web.ts` (public vars of apps/web and apps/admin), `driver.ts` (public vars only).
- `packages/db` database helpers (PLAT-5): root entry `createAppPool`, `withUnitOfWork`, `getUnitOfWork`, `ScopedRepository`, `getContext`, `verifyPoolRole`, `uuidv7`; `/platform` (elx_platform pool, `withPlatformUnitOfWork`, the cross-tenant door `withCrossTenantUnitOfWork`, `PlatformRepository.unscoped()`), `/migrate` (runner, advisory lock, history check), `/admin` (superuser scratch-db helpers, local/ci), `/testing` (context setter, `transactionOf(uow)`). A unit of work exposes no `tx` (PLAT-6, M-1 structural fix): only the repository bases reach the transaction. Migrations live in `apps/api/drizzle/` (reviewed SQL, `-- reviewed` header); integration harness `apps/api/test/integration/global-setup.ts` migrates a scratch database per run. `packages/i18n` `ar`/`en` catalogues, typed `t()`; `/errors` entry (`errorMessage`, `fieldMessage`; JSON with import attributes so the API's Node loader can read it; the root entry is bundler-only). `packages/ui` Radix + Tailwind tokens. `packages/contracts` (PLAT-15): Redocly lint with repo rules (`redocly/plugin.js`, catalogue `docs/contracts/permissions.yaml`), per-surface bundles + Orval clients/hooks/Zod/MSW + unions under `generated/` (gitignored, built by `build`, never committed or edited); entry points `./{staff,platform,public,driver,recipient}` (each also exports `operationSchemas`: strict request Zod schemas + per-status response schemas keyed by operationId, A-17, for the PLAT-6 `ContractPipe`), `./<surface>/mocks` for all five surfaces (test-only, faker seeded), `./<surface>/schemas` (server-safe: model types, enums, `schemas`, `operationSchemas`; no client/hooks/MSW, rule `server-safe-schemas-entries`; what `apps/api` imports), `./http` (`createFetcher`, `apiFetch`, `ApiError`), `./unions` (`Permission`, `StreamEventName`, `ErrorCode`, `isStreamEventName`, and the state lists `orderStates`/`offerStates`/`attemptStates`/`custodyStates` with their `*State` types from components.yaml (WEB-1); SSE wildcard families expanded at build time from `docs/architecture/domain-model.md` §6.3, so that file is a contracts build input and re-included in `.dockerignore`); contract-test harness `test/contract/` (`ContractValidator`: ajv 2020-12 over a closed copy of the bundle, `unevaluatedProperties: false` injected at value locations → `undocumented_field`) with scenarios in `test/scenarios/<surface>/<operationId>.ts`. `packages/config` also exports `./contract-test` (`contractTestConfig()`, `CONTRACT_API_URL` only; the fourth file allowed to read `process.env`). `packages/config-ts`, `packages/config-eslint` shared configs.
- `tools/native-stack.sh` Homebrew stack (no Docker on owner's Mac); `tools/stack.sh` Compose stack pairs; `tools/pr-gate.sh <PR>` merge gate.
- Governance: `AGENTS.md` (hard rules), `docs/handbook/01..05`, `adr/0000-0037`, `docs/architecture/*.md`, `docs/roadmap.md` (order graph), `docs/orders/<ID>/plan.md`, `docs/orders/README.md` (in-flight ledger).

## Invariants (AGENTS.md hard rules, enforced where stated)
- Every operational row has `account_id`; account from token/request context, never a parameter.
- Ledgers (stock, cash custody, driver liability) append-only; writes only through ledger services.
- External side effects only via outbox (ADR-0024); driver location pings exempt (ADR-0028).
- No `process.env` outside `packages/config` — enforced by shared ESLint `no-restricted-*` rules and dependency-cruiser `environmentRules()` in every workspace's `test:architecture`.
- Database (PLAT-5): only `packages/db` imports `postgres`/`drizzle-orm/postgres-js` (depcruise `database-driver-only-in-packages-db`); `/platform` only from `modules/kernel/platform/`, `src/worker/system/`, `src/seed/`; `/testing` never in `src/`; `/admin` only `src/seed/`; ESLint forbids the strings `set_config`/`elx.account_id` outside `packages/db/src` and `.tx` on a unit of work outside `*.repository.ts` (and the type no longer has `tx`); schema test `apps/api/test/schema/tenancy.test.ts` enforces `account_id`, policies, append-only triggers (`nullableAccountTables` in `exemptions.ts` for data §2.4 nullable-account tables).
- Web and driver reach the API only through `@eeasy-logistics/contracts`; dependency-cruiser limits `apps/web` to `/staff`, `/recipient`, `/http`, `/unions` (never `/platform`: that is the admin app, ADR-0038; no `/mocks` in src), `apps/admin` to `/platform`, `/http`, `/unions` (rule `admin-contracts-surfaces`; `/platform/mocks` from `tests/` only, rule `admin-contracts-mocks-in-tests-only`) and `apps/driver` to `/driver`, `/http`, `/unions` (plus `/driver/mocks` from test files only, rule `driver-contracts-mocks-in-tests-only`). Generated code under `packages/contracts/generated/` is never committed.
- Request frame (PLAT-6): JSON bodies only, case-sensitive strict routing, the surface from the matched route template; every API route is authenticated unless `@Public()`; the account comes only from the token (surface cookie or bearer), never path/query/body; platform staff reach tenant rows only through `@CrossTenant()` (reason header, audit event); every error is the contract `Error` schema via the global filter.
- Bounded contexts `kernel`, `delivery`, `wms`: kernel imports no context; a context imports another only via `modules/<ctx>/public/` — dependency-cruiser in `apps/api`.
- API types come only from `@eeasy-logistics/contracts` (doc 3 §9, roadmap A-17): no hand-written DTOs, no `class-validator`/`class-transformer`/`nestjs-zod`/`@nestjs/swagger`; strict generated Zod schemas parse every controller input through the kernel `ContractPipe` (PLAT-6); contract types only in `*.controller.ts` and `*.presenter.ts`; services, repositories and Drizzle keep their own types. Enforced by `apps/api/.dependency-cruiser.cjs` rules `no-validation-libraries`, `no-dto-files`, `contracts-only-in-controllers-and-presenters` (violation fixtures in `apps/api/test/architecture/violations/`, asserted by `test/architecture-violations.test.ts`).
- Every string in `ar` and `en`; Arabic default and RTL (ADR-0016). Gregorian dates, Western digits: format only through `@eeasy-logistics/i18n` `format.ts` (no date library); the census fails on Arabic-Indic digits.
- Logical CSS only: ESLint `eeasy/no-physical-direction-utilities` (`packages/config-eslint/rules/`, exported as `logicalCss`, on in `packages/ui`, `apps/web`, `apps/admin`) reports `ml-`/`mr-`/`pl-`/`pr-`/`left-`/`right-`/`text-left`/`rounded-l-`/`border-r-`/`float-left` and the like in `className`/`class` and `cn(`/`clsx(`/`cva(`/`tv(` (object keys count under `cn`/`clsx`, not under `cva`/`tv` variants), with the logical replacement; fixtures in `packages/config-eslint/test/fixtures/`.
- New modules behind rollout mode, default allowlist (ADR-0006).
- Never commit to `main`; one order → one PR; plan file first commit on `feat/<ID>-<slug>`.

See `mem:tech_stack` for versions, `mem:suggested_commands` for running things, `mem:conventions` for code style and plan-file rules, `mem:task_completion` for the done checklist. Read `mem:memory_upkeep` before finishing any change to scripts, pins, modules, lint rules or conventions: it lists which memory each kind of change must update.
