# Done checklist (handbook 02)

Run from the repo root unless noted; all must be green before a PR leaves draft.

1. `pnpm turbo run typecheck lint test --filter=<changed workspaces>...` then the full `pnpm turbo run typecheck lint test build` once.
2. API behaviour change: `pnpm --filter @eeasy-logistics/api run test:integration` with `DATABASE_URL_ADMIN` set, once with `ELX_RLS=off` and once with `ELX_RLS=on` (CI lanes `api-test` and `api-test-rls` run `migrate`, `seed`, contracts `build`, `test:unit`, `test:integration`, `test:architecture` with `APP_ENV=ci`) — real PostgreSQL, never a mock; show red-then-green in the PR. A new table: policies and `account_id` per the schema test, exemptions in `apps/api/test/schema/exemptions.ts`.
3. Architecture rules: `test:architecture` in every touched workspace (runs inside `test`).
4. Web UI change: `pnpm --filter @eeasy-logistics/web run test:census` (port 3001; a new screen adds its `census-*.spec.ts` to `testMatch` in `tests/census.config.ts`) or `pnpm --filter @eeasy-logistics/admin run test:census` (port 3002, CI lane `admin-build-census`) in `ar` and `en`, plus `check:budget` for the app after `build` (census build values, `mem:suggested_commands`; a new screen that sends product events declares them with `expectAnalyticsEvents`); Arabic RTL screenshot reviewed; `ar`+`en` keys added; Arabic release note.
5. Driver change: `pnpm --filter @eeasy-logistics/driver run test` and `doctor`.
6. Contracts touched: `pnpm turbo run typecheck lint test --filter=@eeasy-logistics/contracts...` (regenerates, lints with repo rules, typechecks `generated/` and the apps that import it). New API operation: its contract scenario, run with `pnpm --filter @eeasy-logistics/contracts run test:contract -- --api <origin>` against the running API (CI: `web-build-census` steps "Point the API at the ci database and migrate it" (PLAT-11: a throwaway signing and credentials key, the ci database migrated, `.env.example`'s public URLs, in `$RUNNER_TEMP/api.env`) and "Contract tests against the API" (with `--web-origin`/`--admin-origin`); `typecheck-lint` step "Contracts generate twice and compare" hashes two fresh generations).
7. `pnpm format:check`; dependency added or bumped: `pnpm audit --audit-level moderate` clean.
8. Plan `docs/orders/<ID>/plan.md` §8 complete (8.0 progress rows per item, 8.1–8.3); `.serena/memories/` updated if a convention, command, invariant or source-map entry changed (see `mem:memory_upkeep`).
9. PR body from `.github/pull_request_template.md` with exact counts; then `tools/pr-gate.sh <PR>` must print `GATE PASS`. A script that starts reading a doc adds that path to `tools/changed-scope.sh`, or docs-only PRs would skip the lane that needs it.
