# apps/admin

- Platform console (ADR-0038, WEB-19): Next.js 16.4 App Router, same pins, tsconfig, ESLint and `turbo.json` (`^build`) as `apps/web`. Own standalone image (`apps/admin/Dockerfile`, port 3000 in the image) and hostname (`PUBLIC_ADMIN_URL`, local `http://localhost:3002`).
- Route groups `src/app/(auth)` (`/sign-in`, `/sign-in/totp`) and `(platform)` at `/` (no `/platform` segment); each its own root layout in the shared shell (WEB-1 leg 2), same shape as `apps/web` (`mem:web/core`): `(platform)` passes `AppShell` an `account` block (the console name until WEB-2) and placeholder navigation groups (accounts, operations, staff and audit; links to future paths answer 404 until their orders); `(auth)` top bar only. Tailwind via `postcss.config.mjs`; `next.config.ts` = web's (next-intl plugin, `transpilePackages` incl. `ui`, nosniff header).
- Strings: the `platform` namespace lives only here, `messages/{ar,en}/platform.json` (ADR-0038), never in `packages/i18n`. `src/i18n/messages.ts` exports `appMessages` and augments `AppMessages` of `@eeasy-logistics/ui/intl` (typed keys); `src/i18n/request.ts` is `shellRequestConfig(appMessages)`. The client provider gets no `platform` strings (labels are translated on the server and passed as props). Parity: `packages/i18n` `test/parity.test.ts` covers this root too.
- Census (WEB-1 leg 2, WEB-2 leg 2): `tests/census.config.ts` + `tests/census/helpers.ts` are copies of web's (base URL `http://localhost:3002` since WEB-2: the API's marker wants `PUBLIC_ADMIN_URL`'s exact Origin), specs `census-shell` (`/`, `/sign-in` + locale switch), `census-errors`, `census-analytics`, `census-auth` (60 tests over `ar`, `ar-390`, `en`); baselines `tests/census/__screenshots__/<project>/<name>-<platform>.png`. Scripts `test:census`, `check:budget` (runs `../web/scripts/check-budget.ts`).
- Config: public values via `@eeasy-logistics/config/web` (`publicConfig()`, same `NEXT_PUBLIC_*` set as web). Contracts: `/platform`, `/http`, `/unions` only (`admin-contracts-surfaces`); `/platform/mocks` from `tests/` only (`admin-contracts-mocks-in-tests-only`).
- Ports: dev/start 3002; CI lane `admin-build-census` (API 3000, admin 3002; build → `check:budget` → census); `main.yml` image `ghcr.io/marllow-git/eeasy-logistics/admin`, probed with `GET /`.
- Not built yet: screens (WEB-4), per-host edge 404 (OPS-1).
- Observability (PLAT-14 leg 2): a copy of apps/web's (`mem:web/core`): groups `platform` and `auth` in `RouteError`/the catalogue, `serverName` `elx-admin`, census specs `census-errors.spec.ts` and `census-analytics.spec.ts`; `tests/census/helpers.ts` is web's copy except its `message()` (reads `platform` from `messages/`).
- WEB-2 leg 1: `src/proxy.ts` (platform cookies `el_platform_at`/`_rt`, `adminGroupOf`: `/sign-in*`, `/signed-out`, `/invitations/*` auth, the rest session), `next.config.ts` rewrites only `/v1/platform/*`, `src/server/api.ts` (`platformServerFetcher`), `/monitoring/csp`.
- WEB-2 leg 2: `src/server/session.ts` (`getPlatformSession`, React `cache()`: no cookie → `/sign-in?next=` without an API call, 401 → `reason=ended`), `(platform)/layout.tsx` renders `src/session/platform-session.tsx` (`SessionProvider surface="platform"`, re-sign-in = `platformLogin` then `platformVerifyTotp`, `codeDescription` the TOTP line) and `UserMenu`. Doors in `(auth)`: `/sign-in` (no reset link; `reason=ended` adds the 12 h idle line), `/sign-in/totp` (`src/auth/totp-door.tsx`: renders only after hydration from the `sessionStorage` step of `src/auth/steps.ts`; code entry or the enrolment view: `platformEnrolTotp` once per view (ref guard), `QrCode` + `ManualKey`, `platformConfirmTotp`), `/invitations/[token]` (`platformAcceptInvitation` → the TOTP step), `/signed-out`. Census-only `(platform)/census-session`. Analytics `auth.sign_in.started|succeeded` (`surface: 'platform'`, `enrolled`), `auth.session.ended`.
- Census stack (WEB-2 leg 2): same as web's (`mem:web/core`): the API without `REDIS_URL`, a worker, Mailpit, `seed:census` before EVERY run (it resets TOTP and `totp_last_step`, re-sends the platform invitation; a second run without it fails the enrolment and invitation checks). `tests/census/session.ts`: `platformSignIn(page, role, project)` (password then the TOTP code over the rewrite), `totpCode` (RFC 6238, a copy of the API's `totp.ts`), `wrongCode`, `mailedLink`. Trap: the API accepts each TOTP step once per user (replay guard, ±1 step), so each census check has its own seeded user (`census-platform-<role>-<project>@census.test`) and `platformSignIn` tries steps −1, 0, +1 then waits for the next step. Clearing cookies in a test must keep `el_locale` (`clearCookies({ name: /^el_platform_/ })`), or the `en` project falls back to Arabic.
