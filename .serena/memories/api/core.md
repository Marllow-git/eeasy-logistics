# apps/api

- NestJS 12, ESM. `src/main.ts` parses `--role api|worker|migrate` (`src/role.ts`; `migrate` runs `src/migrate/run.ts`) and boots through `@eeasy-logistics/config` `loadConfig()`; exit 78 on config error.
- Contexts: `src/modules/kernel|delivery|wms/`, each with `<ctx>.module.ts` and `public/index.ts` (the only cross-context import surface). Kernel imports no context.
- `src/health/` → `/health` (no dependencies) and `/ready` (`AppModule.forRoot(config)` only: elx_app role check, schema version at or beyond the build's, Redis PING, S3 HeadBucket; cached 2 s).
- Kernel schema `src/modules/kernel/schema/`: `core_accounts` (platform table, elx_app SELECT only), `core_schema_meta` (version for `/ready`), `core_idempotency_keys`, `core_audit_log` (types only; partitioned by hand in SQL). `drizzle.config.ts` globs `src/modules/*/schema/*.ts` into `drizzle/`.
- Migration runner trap: Drizzle's migrator compares only the journal `when` with the last applied row and silently skips a back-dated file; it never re-checks applied hashes. `packages/db/migrate` refuses both (edited/removed applied file, file older than the last applied) — regenerate a back-dated migration instead of forcing it.
- Build (CHORE-1): `nest build` uses SWC (`nest-cli.json` `builder: "swc"`, `typeCheck: false`; `typecheck` stays `tsc --noEmit`). No `.swcrc`: Nest CLI 12's defaults apply (ESM `es6` with `resolveFully` because `type: module`, `legacyDecorator` + `decoratorMetadata`, `useDefineForClassFields: false`, target es2021, helpers inlined so no `@swc/helpers` at run time). Adding a `.swcrc` merges over those defaults. Vitest never uses this build; check DI changes against `dist/` by booting it.
- Tests: `*.test.ts` beside code (Vitest unit); `test/*.http.test.ts` HTTP tests with supertest; `test/integration/` and `test/schema/` run only via `vitest.integration.config.ts` (scratch database from `global-setup.ts`; helpers `integrationConfig()`, `connectAs(role)` in `support.ts`; scratch tables go in a throwaway schema, never `public`, and runtime roles cannot create temp tables); `test/architecture/` fixtures prove the dependency-cruiser rules.
- Database roles (ADR-0031): `elx_owner` (migrations), `elx_app` (RLS-scoped app pool), `elx_platform` (cross-tenant, `@CrossTenant()`), `elx_maintenance`. Never migrate the shared dev database from an executor.
- Request pipeline (PLAT-6, `src/modules/kernel/`): `request/request-id.ts` middleware first (UUID kept, else UUIDv7; `RequestLogger` prefixes log lines) → global `tenancy/tenancy.guard.ts` (`@Public()` skips auth but not the rate limit; surface from `/v1/<surface>`; `auth/principal.ts` reads `el_staff_at` / `el_platform_at` cookies or the driver bearer; `auth/access-token.ts` jose HS256, `kid`, Zod claims per surface; recipient/public 401; then charges `rate-limit/` per user/device, else client IP for public routes and refused credentials: README §7 budgets in `budgets.ts`, one Lua `INCR`+`PEXPIRE` per fixed minute under `elx:rl:<surface>:<bucket>:<identity>`, `RateLimit-*` headers, 429 with `Retry-After`; Redis down fails open with one warning a minute and `failOpenCount`; no `REDIS_URL` → no limiter) → global `request/web-client.guard.ts` (staff/platform non-GET/HEAD/OPTIONS need `X-EL-Client: web` and `Origin` = origin of `PUBLIC_WEB_URL` (staff) / `PUBLIC_ADMIN_URL` (platform), else 403; unset origin fails closed) → global `tenancy/unit-of-work.interceptor.ts` (staff/driver `withUnitOfWork` on elx_app; platform `withPlatformUnitOfWork`; `@CrossTenant()` → reason check, one platform-pool transaction that checks the account exists then sets `elx.account_id` = `:account_id`, one committed `core_audit_log` row per attempt (PLAT-7); commit on 2xx) → route `@Idempotent()` (`idempotency/`, reserve in the same transaction) → global `contract/contract-pipe.ts` (`APP_PIPE`; acts on `@Input()` only: handler binds `@Operation(operationSchemas.<id>)` from its contracts server-safe entry `@eeasy-logistics/contracts/<surface>/schemas` (never the barrel `/<surface>`: client and hooks; rule `contracts-server-entries-only`; the image builds the contracts and copies `generated/`), gets `ContractInput<typeof op>` with path/query/declared headers (case-insensitive pick)/body parsed by the generated strict schemas; 400 `validation_failed` with `/path|/query|/header|/body/...` pointers; the kernel never imports contracts) → handler (`getUnitOfWork()`, `getContext()`) → global `errors/exception.filter.ts` (`ApiException(code)`, status from `errors/error-codes.ts`, message from `@eeasy-logistics/i18n/errors` by `Accept-Language`). Configured parts come from `request-frame.module.ts` and `platform/platform.module.ts` (`AppModule.forRoot`); without them every non-public route is refused.
- Platform pool and boot: `platform/platform.module.ts` (pool, `PlatformFrames` port), `platform/boot-checks.ts` (`main.ts` exits 78 naming the role), `platform/accounts.repository.ts`, `platform/idempotency.repository.ts` (account NULL keys). `--role worker`: `src/worker/system/` (`WorkerModule`, hourly `purgeIdempotencyKeys` under Redis lock `elx:lock:idempotency-purge`, daily audit partition job; a job missing its variables warns `<job> disabled: ... not configured`, and with no job left the worker exits 0, as the image probe expects). Both idempotency stores share `idempotencyStatements(scope, ttlHours)`.
- Kernel schema adds `core_idempotency_keys` (migration 0005, nullable account, NULLS NOT DISTINCT unique). A new error code goes into `docs/contracts/errors.md`, the `errorStatus` table and both `packages/i18n/*/errors.json` together (parity test `errors/error-codes.test.ts`).
- Test helpers: `test/support/access-tokens.ts` (test-only signer, random key per file; pass `AUTH_SIGNING_KEY_ID`/`AUTH_SIGNING_KEY` to `integrationConfig`), `test/integration/probe-table.ts` (scratch tenant table with policies). `/ready` integration tests need storage on 9000 (MinIO/Silo); without it 3 of 4 fail.
- A-17 sample: `test/contract-sample/` (`platformListAccounts` controller, presenter returning the generated `PlatformListAccounts200`, Drizzle-typed repository; test-only).
- Test traps: `integrationConfig()` defaults `PUBLIC_WEB_URL`/`PUBLIC_ADMIN_URL` (ci reads no `.env`); staff/platform write tests send `webClientHeaders(config, surface)` (`test/support/web-client.ts`); an `@Idempotent()` route needs a real `core_accounts` row (FK) for the token's account; rate-limit tests use a fresh key prefix per run (shared Redis). API unit tests import `@eeasy-logistics/contracts` → `pnpm --filter @eeasy-logistics/contracts run build` first (turbo `^build` via `apps/api/turbo.json`; CI step in `api-test`).
- Audit log (PLAT-7): `core_audit_log` (migration 0006, hand-edited generate) range-partitioned by month (`core_audit_log_YYYYMM`, UTC), PK `(id, occurred_at)`, append-only trigger on the parent cloned to partitions, no runtime grant on any partition, owner-only `core_ensure_audit_partitions(n)` / `core_drop_audit_partitions_before(date)` (refuses a cutoff inside 24 months; both take an advisory lock); `runMigrations` ensures 3 months ahead in the version transaction. `modules/kernel/audit/`: `AuditWriter` behind `AUDIT_SINK` (`record()` in the unit of work, `recordCommitted()` via `@eeasy-logistics/db/committed`), `redaction.ts`, signed keyset `cursor.ts` (`CURSOR_CODEC` from `RequestFrameModule`), the first kernel controllers in `src/` (`listAuditLog`, `platformListAccountAudit`, `platformListAudit`), presenter. Platform-side appender/reader in `platform/audit-log.repository.ts`. Door rows: `platform.cross_tenant.refused` (account NULL) / `.accessed` with `after.outcome`, written after the door transaction settles. `@CrossTenant({ from: 'query', name })` is the declared query form. Worker job `src/worker/system/audit-partitions.ts` (daily, lock `elx:lock:audit-partitions`, `maintainAuditPartitions` from `/migrate` as elx_owner); the only worker reader of the owner URL (ESLint owner-url rule, depcruise `db-migrate-only-in-owner-jobs`).
- Audit test traps: read rows back with `test/integration/audit-rows.ts` by the response's `X-Request-Id` (server id when the client sent none); accounts with audit rows can never be deleted (FK, K-7), so tests leave them; plant rows inside an existing month (`date_trunc('month', ...)` + offset: on the 1st, `now() - 1h` has no partition); postgres.js turns a string bound to a `timestamp` parameter into a local-time Date: cast `${s}::text::timestamp`; DDL takes no parameters (`tx.unsafe`); a test that creates or drops partitions goes in `migrate.test.ts` (files run in parallel).
- Upcoming shape (roadmap): PLAT-8 outbox + BullMQ queues per kind; PLAT-10 `x-permission` enforcement and before/after rows through `AuditWriter`.
- Review round 2: `src/http-app.ts` `configureHttp()` sets Express `trust proxy` = `TRUST_PROXY_HOPS` (`config.app.trustProxyHops`, default 0, production api ≥ 1: Cloudflare) so `request.ip` is the client the edge saw; `@CrossTenant()` routes use `:account_id`; every `@Idempotent()` handler needs `@HttpCode()` (`IdempotentRoutesCheck` fails boot otherwise).
- Adversary pass (PLAT-6): `main.ts` builds Express through `createHttpAdapter(config)` (case-sensitive and strict routing, `trust proxy`; must be set before Nest touches the instance, Express builds its router on the first `use()`) with `httpAppOptions` (`bodyParser: false`) and `configureHttp()` (JSON parser only); global `request/content-type.guard.ts` refuses non-JSON bodies; surfaces come from `requestSurface(request)` (route template), never the raw path. Units of work are retired when the transaction settles (`UnitOfWorkClosedError` from `packages/db`; repositories resolve the transaction per statement). Idempotency request hash = HMAC under the HKDF key; `secretResponse` stores `{ id }` only. Audit/log request id is server-minted (`serverRequestIdOf`), the client's is `clientRequestId`. ESLint forbids raw `@Body/@Query/@Param/@Headers/@Req/@Request` in controllers outside the kernel (fixture `test/architecture/violations/lint/`, linted by the violations test).
