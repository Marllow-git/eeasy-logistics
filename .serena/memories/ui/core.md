# packages/ui and packages/i18n (WEB-1)

## packages/ui (ADR-0033)
- Source only, compiled by the apps (`transpilePackages`). Entry points: `./styles.css` (Tailwind 4 `@import 'tailwindcss'`, tokens, `@source '.'`, per-`lang` line height), `./tokens.css`, `./cn`, `./status`, `./intl`, `./components/<name>` (→ `src/components/<name>/<name>.tsx`), `./shell` (server: `RootHtml`, `rootMetadata`, `requestLocale`, `localeCookie`), `./shell/request-config` (`shellRequestConfig(appMessages?)` merges an app's own namespaces; the default export has none and is what apps/web re-exports), `./shell/locale-switch` (client).
- Tokens `src/tokens.css`: a Tailwind `@theme` block (semantic colours incl. `surface`, `input`, `ring`, `*-foreground`; `--font-sans: var(--font-plex), …`; `--leading-ar-*` above `--leading-en-*`; spacing, radius, shadow, motion) plus `:root` `--status-<machine>-<state>` for order/offer/attempt/custody. `test/tokens.test.ts` computes WCAG ratios from the file (text 4.5:1 on background/surface/muted, controls 3:1, every status token 4.5:1).
- `src/status.ts`: the four state lists come from `@eeasy-logistics/contracts/unions` (`orderStates`, `offerStates`, `attemptStates`, `custodyStates`, generated from components.yaml; lead ruling WEB-1 review 1: both apps may import `/unions`). A new contract state fails typecheck in `StatusChip` until it has an icon and a label, and the token test until it has a colour; an unknown state at runtime renders a neutral chip with the raw text and a `console.warn`.
- `AppShell` props: `brand`, `navigation: NavigationGroup[]` (`{ label?, items }`; `NavigationItem.children` unfold only under the current item), `account` (sidebar top), `sidebarAction` (sidebar bottom), `search` (top-bar middle), `topBar` (end). `PageHeader` has `actions` (end) and `tabs` (row under the title). Patterns from the owner's Mobbin references, `docs/references/design/WEB-1.md`.
- Components: Radix through the umbrella `radix-ui` package, `cva`, `lucide-react`; `src/intl.ts` holds the next-intl `AppConfig` augmentation (Locale, `Messages & AppMessages`; `AppMessages` is empty here and augmented per app, apps/admin adds `platform`) and re-exports `useLocale`/`useTranslations`; translate through it so every program sees the typing. `<Money>` puts the riyal SVG where `Intl.NumberFormat` puts the currency (`formatMoneyParts`: after the amount in Arabic, before it in English) with a no-break space. Toast swipe direction comes from the Radix direction; Dialog centres with `inset-0 m-auto`.
- Fonts: `fonts/IBMPlexSansArabic-{Regular,SemiBold}.woff2` are the official unmodified files of `@ibm/plex-sans-arabic` 1.1.0 (`fonts/complete/woff2`, 71,904 and 76,408 bytes; never subset them: the OFL Reserved Font Name "Plex" forbids a modified file under that name; a renamed subset is the fallback only if a budget fails), licence `fonts/OFL.txt`; loaded by `src/shell/font.ts` (`next/font/local`, variable `--font-plex` on `<html>`).
- Tests: Vitest + Testing Library in jsdom 26 (`vitest.config.ts`); `test/render.tsx` `renderIn(locale, ui)` (NextIntlClientProvider + DirectionProvider + `<html lang dir>`); every component in `describe.each(directions)`. Radix roving focus moves in a timeout: assert with `waitFor`.
- No server actions anywhere (web §2.2): `LocaleSwitch` writes `el_locale` with `document.cookie` and calls `router.refresh()`.
- WEB-3 entry points: `./query` (`QueryProvider` inside `SessionProvider`: `staleTimes` session/reference 5 min, list 30 s; no retry on 4xx; a 403 `forbidden`/`feature_not_enabled` raises the window event `elx:session-stale` and the provider calls `router.refresh()` (a new `getMe`) at most every 5 s; sign-out clears the cache through `useSignOutCleanup`, new in `./session`), `./authz` (`Can permission fallback="hidden"|"disabled" reason`, `useCan`, `DisabledWithReason`: tooltip on a focusable wrapper plus an sr-only `aria-describedby`), `./form` (`useContractForm(schema, defaults, { disabled })`, `Form`, `SubmitButton` (disabled until dirty, "Saved" status, failure alert, held for `Retry-After`), `FormField`, `fieldCodeResolver` (Zod messages replaced by the `errors.fields` codes), `pointerToPath`, `changedValues` (top-level keys with any dirty marker, whole value), `useIntentKey` (UUID v7, renewed after success)), `./form/fields` (Text, Number (empty = `NaN`, because generated bodies `.default()` some numbers and undefined would take the default), Select, RadioGroup, Switch, CheckboxGroup, Bilingual), `./table` (`DataTable` on TanStack Table v9: `sortField` headers with `aria-sort`, `nextSort`, "N shown", load more, column menu persisted at `elx:table:<id>`, virtualised above 200 with spacer rows), `./table/list-params` (`useListParams` replaces the URL), `./table/cursor-list` (`useCursorList` over `useInfiniteQuery`; Orval generates no infinite hooks), `./settings/reason-codes` (`ReasonCodesEditor`, `reasonCodesSection`: the generated row extended with the code pattern, one-line labels of 1 to 80 code points, unique codes). New primitives `components/switch`, `checkbox`, `radio-group`, `DropdownMenuCheckboxItem`. Traps: jsdom has no ResizeObserver (Radix Switch/Checkbox): stubbed in `test/render.tsx`; a Radix menu opens in jsdom on `keyDown Enter`, and while open hides the rest from `getByRole` (`{ hidden: true }`); the React Compiler lint (`react-hooks/refs`) reads `field.*` as a ref when `ref={field.ref}` is passed in a component body: destructure `ref` first; it also warns "Compilation Skipped" on `useTable` (expected).
- WEB-3 leg 2: `components/confirm-dialog` (`ConfirmDialog` on Radix `AlertDialog`: title, consequences list, Cancel, a busy confirm, the intent's key across retries, `describeError` for a page's own refusal text), `./table/filters` (`ChipFilter` toggle chips with "All", `SelectFilter` with an `__all` sentinel, `SearchFilter` debounced with `valid`/`invalidMessage`, `DateFilter` `YYYY-MM-DD`), `./settings/status-chips` (`MemberStatusChip`, `RoleChip`, `SiteStatusChip`, `SiteKindChip`; `apps/web` has no `lucide-react`), `./settings/site-form` (`siteFormSchema` with a transform to the whole site body, `siteFormValues`, `ShortCodeField`, `PointFields`, `OpeningHoursEditor`; `oneLine` now exported by `reason-codes`), `TextAreaField`, `NumberField decimal`, `FieldOption.reason` (a disabled option wrapped in `DisabledWithReason`), `Form describeError`, `form/intent-key.ts` (`useIntentKey` without the form library), `fieldCodeOf` maps an empty required list to `required`. Traps: jsdom has no `scrollIntoView` (Radix Select on open): `test/members-kit.test.tsx` defines it; `act()` with a sync callback returns a thenable the lint wants `void`ed.

## packages/i18n
- Catalogues `<locale>/{common,nav,auth,errors,recipient,settings}.json` (`settings`: WEB-3; `common.form`, `common.table`, `common.authz`, `common.no_access`) (`platform` is apps/admin's, `apps/admin/messages`; `test/parity.test.ts` checks both roots and that `platform` stays out of this one); `src/messages.ts` `messages`, `Messages` (from `ar`), `Namespace`, `pickMessages(locale, namespaces)` (root layouts pass only their namespaces to the client); `src/locale.ts`; `t(locale, CommonKey)` for the driver and metadata (no ICU).
- `errors` is PLAT-6's `{ codes, fields }` catalogue (also the `./errors` entry the API loads with JSON import attributes); `errors.codes` has one message per `ErrorCode` (`test/errors.test.ts` compares with `@eeasy-logistics/contracts/unions` `errorCodes`, so the i18n `test` depends on the contracts `build`). `src/locales.ts` holds `locales`, `defaultLocale`, `isLocale`, `dir` without catalogues, for the API's Node loader.
- `src/format.ts`: `formatDateTime`, `formatDate` (business dates in UTC from their parts), `formatNumber`, `formatMoney` (`SAR 150.00`), `formatMoneyAmount`, `formatPhone` (LRM-wrapped), `intlLocale` (`-u-ca-gregory-nu-latn`), `timeZone`. ICU plurals take a pre-formatted `{value}`; never `#` (bare-locale digits).
- No next-intl dependency (the driver app uses this package); tests use `use-intl/core` `createTranslator`.
- PLAT-14 leg 2: `components/error-state` (`ErrorState`: heading, line, LTR reference with copy + sr-only status, retry, optional home; `variant` `section` | `page`; strings as props), `./shell/global-error-document` (client: `GlobalErrorDocument`, own `<html lang dir>` from the `el_locale` cookie via `useSyncExternalStore`, Arabic on the server), `./observability` (pure, no SDK: `redactText` (4 kB cut, lookbehind-anchored patterns), `scrubUrl`/`scrubPath` (`:token` after track/reschedule/pin/invitations/password-reset, token-shaped segments, `:phone`), `isSecretKey` (the API audit key-token rule: split on `_ - .` and camelCase, any token or adjacent pair in the secret set), `scrubSentryEvent`, `filterSentryEnvelope`, `scrubAnalyticsEvent` (drops secret-named keys at any depth, `$title` and referrers), `readCappedBody` (the routes' streamed size cap: 411 without a length, 413 over the cap), `isRecipientPath`; tests `test/observability.test.ts`, `test/error-state.test.tsx`). Error-page strings: `common.error_page` in packages/i18n.
- WEB-2: `src/session/`: `tokens.ts` (`accessTokenExpiry`, `accessTokenStale` 60 s margin, `safeNextPath` (same-origin relative only, not `/sign-in*`), `signInPath`), `headers.ts` (`contentSecurityPolicy`, `securityHeaders`, `newNonce`, `cspViolations`), `proxy.ts` (`createSessionProxy`, `isNavigation` (refuses `Next-Router-Prefetch`, `Next-Router-Segment-Prefetch`, `Sec-Purpose`/`Purpose: prefetch`), `rewriteCookieHeader`, `pathHeader`; trap: a proxy cannot return a relative `Location` on Next 16.4.3, the adapter's `new NextURL(location)` throws, so redirects are built on the public origin and the adapter relativises same-host ones), `csp-sink.ts` (`./session/csp-sink`: `createCspReportSink`, the `POST` of both `/monitoring/csp` routes: report media types only (415), 30 a minute per last `X-Forwarded-For` entry and 300 per process (429), five violations a body, one line per (directive, origin) a minute), `session-provider.tsx` (`./session`: `SessionProvider` over a `SessionController` class (no refs read in render: the React Compiler lint refuses them), `useSession`, `usePermissions`, `useSessionFetcher`, `useSignOut`, `useUnsavedState`, `sessionNavigation` (replaceable in jsdom); optional `codeDescription` for the dialog's code step), `user-menu.tsx` (icon always, the name from `sm` up). `src/auth/*.tsx` (`./auth/*`): `AuthCard`, `PasswordField`, `CodeInput` (dir ltr), `PhoneField` (+966, `saudiMobileE164`), `ResendButton`, `QrCode` (`qrcode` modules as one SVG path), `ManualKey` (+ `secretFromOtpauth`, `keyGroups`: the base32 key in groups of four, dir ltr, copy control), `ReSignInDialog`, `error-message.tsx` (`useErrorMessage`, `retryAfterSeconds`). Observability scrubbers: `enrol` is a token marker, `challenge` and `otpauth` secret key tokens. i18n: the `auth` namespace covers every door of WEB-2 (console TOTP strings included).
