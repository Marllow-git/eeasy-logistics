## 0. Goal

Both web applications render inside one design system that is right-to-left first: Radix behaviour, Tailwind styling with logical utilities enforced by lint, tokens as CSS custom properties, IBM Plex Sans Arabic self-hosted, next-intl with Arabic as the default locale, one formatting module for dates, numbers and money shared with the driver app, and a Playwright census harness in `ar` and `en` with the locale, RTL, accessibility and security assertions of the web document, so that every later screen order adds pages and specs into a frame that already enforces ADR-0016.

### 8.2 Interpretations the lead should check

1. **next-intl typing lives in `packages/ui/src/intl.ts`**, not in `packages/i18n`: the augmentation needs next-intl, which the driver app (an `i18n` consumer) should not carry. `packages/i18n` exports `Messages`; its own typed-key test uses `use-intl/core`.
2. **ICU plurals take `{value}`** (pre-formatted by `formatNumber`) instead of `#`, because `#` formats with the bare locale, whose digits ADR-0016 does not control.
3. **`formatMoney` returns code text** (`SAR 150.00`; Arabic `‏150.00 SAR` with marks), used for text-only contexts; `formatMoneyAmount` (`150.00`) was added for `<Money>`, which draws the sign as SVG. `en` also carries `-u-ca-gregory` (plan wrote `en-SA-u-nu-latn`); explicit and harmless.
4. **State lists are typed against `@eeasy-logistics/contracts/staff` model types** (type-only), because `unions` has no state enums. `apps/admin`'s `admin-contracts-surfaces` rule will flag it if admin ever imports `StatusChip`; leg 2 only needs `AppShell`. The clean fix is state unions in the contracts `unions` entry (PLAT-15's area).
5. **Lint rule scope**: exported as the `logicalCss` config; `inset-x-*`, `mx-*`, `space-x-*` are symmetric and allowed; corner radii (`rounded-tl-` → `rounded-ss-`), `scroll-m*`/`scroll-p*`, `clear-left/right` and variant-prefixed forms (`rtl:ml-2`) are flagged too.
6. **Toast** swipe direction follows the Radix direction (left in Arabic); its region labels are localised (`common.shell.notifications`), since Radix defaults to English.
7. **jsdom 26.1.0** (already in the lock through Vitest) instead of 30.x, whose CSS packages were under three days old.
8. **Locale switch without a server action**: web §2.2 bans `"use server"` in waves 0 to 4, so `LocaleSwitch` writes `el_locale` with `document.cookie` (a preference, not a credential) and calls `router.refresh()`; the census proves `<html lang dir>` flips.
9. **Auth and recipient pages render inside `AppShell` with `navigation={[]}`** (top bar with brand and locale switch only). Recipient locale is `el_locale` else `ar` per plan 2.4, not web §5's `?lang=` chain (the recipient order's).
10. **A missing message always throws** (shared request config `onError`), not only in a test build: only `packages/config` may read the environment, and keys are typed, so a miss is a bug.
11. **`platform` namespace**: in `packages/i18n` per plan 2.4, while ADR-0038 says it lives only in `apps/admin`. The merchant client never receives it (`RootHtml namespaces`); the server-side message object of `apps/web` does contain it.
12. **Census scope**: `apps/web` has three placeholder routes (plan said four); the fourth test is the locale-switch flow. Projects are named `ar`, `ar-390`, `en`. Baselines are per platform (`-darwin` committed now; `-linux` from the CI artifact, 8.3).
13. **Session-cookie assertion**: staff and platform cookies are host-only `Path=/` (web §3.1), so a browser holding one would send it to `/track` too; the census asserts that no recipient request carries and no recipient response sets `el_staff_*` / `el_platform_*`. It becomes meaningful when WEB-2 issues cookies.
14. **`X-Content-Type-Options: nosniff`** is set in `next.config.ts` `headers()`; WEB-2 may move header handling into `proxy.ts` with the CSP.
15. **README** (outside the listed paths): the `web-build-census` row named `test:smoke`; it now names `test:census` and the baseline update step.
16. **Lockfile**: main's lock pins 78 versions under three days and `semver@6.3.1` with a trust downgrade, so any non-frozen install fails. Each install here added a temporary `minimumReleaseAgeExclude` for exactly those pinned versions plus `trustPolicyExclude: semver@6.3.1`, then restored `pnpm-workspace.yaml` (unchanged in the diff). Against main's lock, 121 package versions were added, 0 removed, all published more than three days ago (script over the `packages:` keys).
17. **OFL Reserved Font Name "Plex"**: subsetting is a modification under the OFL; the subset keeps the internal family name. Many projects ship Plex subsets, but if the owner wants strict compliance the subset needs a renamed internal family (one fontTools step). The CSS family is `next/font`'s generated name either way.
18. **Riyal sign placement**: `<Money>` shows the sign before the amount inside a left-to-right isolate (sign on the left of the numerals); a brand or SAMA-guideline check by the owner is cheap to apply.
19. **Tokens are hex**, not OKLCH, so the contrast test computes WCAG ratios without a colour library.
