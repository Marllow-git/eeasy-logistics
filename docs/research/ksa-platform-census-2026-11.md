# KSA platform census: software comparable to ShipHero, 2026-11

Date: 2026-11-02 (all reads on this date unless marked otherwise). Branch `docs/ksa-platform-census` from `origin/main` at `1e0c184`. Author: researcher agent for the lead.
Scope: platforms that sell WMS, order management, fulfilment-with-software, last-mile delivery management, or shipping aggregation with fleet management, and that have a KSA footprint (SAR pricing, Arabic UI, Saudi customers or offices, or Saudi integrations).

Evidence grades: **[F]** the page was fetched and read on 2026-11-02. **[S]** only a search-result summary was seen, page not opened. **[I]** my inference from a stated fact. "Not on page" means the fetched page did not name it; it does not prove the product lacks it.

## Summary for the lead

1. Platforms in the table were fetched or search-summarised on 2026-11-02. Most global last-mile SaaS (Onfleet, Bringg, Locus, Shipday, Tookan) show no KSA evidence on their own sites.
2. Strongest KSA-native SaaS for list (a): Logestechs (WMS, OMS, delivery and COD, Arabic site, +966) and Shipsy (Monsha'at MoU; no Saudi office on its own site; enterprise API is private).
3. Strongest KSA-native SaaS for list (b): Omniful (Riyadh HQ, WMS, OMS, TMS, public API docs) and Anchanto (Riyadh office, WMS for KSA, public developer portal).
4. Only Wasal publishes SAR price points on its own site (469 and 750 SAR per month). Torod and OTO show SAR as the billing currency but no figures.
5. Torod and OTO both expose public API references, but Torod's linked help centre showed no API section on 2026-11-02; treat Torod API access as unverified.
6. Salla and Zid are commerce platforms that expose shipping and fulfilment app APIs (docs.salla.dev, help-partner.zid.sa); they are integration surfaces, not comparables.
7. Excluded as operators, not SaaS: Lalamove Business, Barq, Careem Express/Box, Bosta, Quiqup, Sirdab, Speed, Sawaq. They are service providers that sell delivery, not software.
8. Zero Saudi evidence was found for Eniverse, Rasid, Sary, Jeel, Dash, Shipdelight, ShipRocket, Stockwise, Flow and Rewaa. They are listed under Unanswered.
9. The feature-coverage note named in the brief (`docs/research/feature-coverage-2026-11.md` §1) is not on `origin/main` or on any branch in this checkout. Product names were taken from `features-wms-2026-11.md` (branch `docs/features-wms`) and `features-orders-dispatch-hubs-2026-11.md` (branch `docs/features-orders-dispatch-hubs`).
10. Shortlists below: four last-mile and four WMS/OMS/fulfilment platforms, ranked by teardown value. Logestechs and Shipsy appear in both lists.

## Shortlist (a): last-mile and dispatch platforms operating in KSA

Ranked by teardown value for eeasy-logistics, which needs driver app, dispatch, COD and proof of delivery in Arabic.

1. **Logestechs** (also in list b). Delivery management with COD, dispatch, tracking and transport management, plus WMS and OMS in one product, with an Arabic site and Saudi phone and integration cues. It is the closest single vendor to the delivery half of our scope. Gap: no public docs, so the teardown depends on product pages and a demo.
2. **Shipsy** (also in list b). The only platform with a Saudi commitment on record (Monsha'at MoU, $10 million over five years in the region; date unconfirmed) and the largest dispatch, route and hub feature set. Hub operations overlap the roadmap's missing hub module. Gap: enterprise API is private, so the teardown is limited to public pages and a sales call.
3. **Wasal**. The only Saudi last-mile SaaS with public SAR prices and an Arabic RTL site, with driver app, COD and POD. It gives a market price anchor for merchant plans. Gap: food-skewed customers, no WMS, no public API.
4. **Safee**. Saudi-first positioning with an offline driver app, POD with QR and barcode, COD workflows and WASL and Madinati integration claims. Those government integrations are relevant to address and national-data handling. Gap: no prices, no public docs, and no named Saudi customers.

Alternates if a teardown slot opens: Shipox (public API docs, COD, driver app; KSA weak), OTO (aggregator with merchant-driver management; borderline on the fleet rule), FarEye (public API docs; KSA only a logo).

## Shortlist (b): WMS, order management and fulfilment platforms operating in KSA

Ranked by teardown value for eeasy-logistics, which needs WMS, OMS and 3PL software for merchants and fulfilment operators.

1. **Omniful** (WMS, OMS, TMS, hubs). Riyadh-based, with a public API documentation site and a Zid integration document. Its OMS, WMS and hub modules cover most of the ShipHero comparison. Gap: Riyadh HQ and customers come from search summaries; the homepage itself shows no Saudi evidence.
2. **Anchanto** (WMS, OMS, fulfilment). Explicit Saudi WMS positioning with a Riyadh office, plus wave, batch, serial and expiry tracking and transfer orders, which match the roadmap's WMS gaps. Public developer portal. Gap: named clients have no stated location.
3. **Fulfillor** (WMS for 3PLs). Saudi-only 3PL WMS with Salla, Aramex, SPL and ASYAD integrations, ZATCA and COD reconciliation. It is the closest KSA-native 3PL software. Gap: no public API docs and no SAR price on the page.
4. **Torod** (shipping aggregator with fulfilment). The only platform reviewed that combines carrier aggregation, storage, packing and inventory sync for Salla and Zid merchants, with SAR as billing currency and an Arabic UI. Gap: API reference is linked but the linked help centre did not show it, so API access is unverified.

Alternates: Aymakan (Riyadh, Arabic, Salla and Zid sync; no software sold), IQ Fulfillment (Zid App Market, inventory and returns), Shipa (Gulf delivery gateways; software not confirmed), Focus WMS (WMS inside an ERP).
